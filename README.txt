SAMIBENMANSOUR.COM — Structure du site
=======================================

PAGES PRINCIPALES
-----------------
index.html          → Page d'accueil
chemin.html         → /chemin — Le parcours narratif
blog.html           → /blog — Liste des billets
publications.html   → /publications — Publications académiques

CV
--
cv.html             → /cv — CV synthétique 2 pages
cv-missions.html    → /cv-missions — CV détaillé par missions

OUTILS & ETIK
-------------
outils.html         → /outils — Les 10 outils
etik.html           → /etik — Page vitrine Etik

RÉFÉRENCES & CLIENTS
--------------------
clients.html        → /clients — Organisations clientes
references.html     → /references — Certificats de missions

CERTIFICATIONS
--------------
shrm-cp.html        → /shrm-cp

DIVERS
------

DOSSIERS ASSETS
---------------
assets/cv/          → Déposer les PDFs des CV ici
assets/certs/       → Déposer les images des certificats ici
assets/publications/→ Déposer les PDFs des chapitres ici
blog/               → Pages des billets individuels (à créer)

DÉPLOIEMENT NETLIFY
-------------------
1. Glisser le dossier entier sur Netlify
2. Le fichier index.html sera servi automatiquement sur samibenmansour.com
3. Chaque autre fichier sera accessible via son nom : samibenmansour.com/chemin, etc.
